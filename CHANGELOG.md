# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-03

### Добавлено
- Сайт-дашборд в светлой теме с тремя уровнями иерархии: главная цель, цели по скоупам, задачи выбранного скоупа.
- Общий прогресс-бар из цветных отрезков: длина каждого равна вкладу скоупа в общий процент.
- Линейные прогресс-бары скоупов в цветах скоупов.
- Подтверждение перед закрытием и возвратом задачи, режим «Изменить список» для добавления и удаления задач.
- Прогресс по весам задач (1–3), а не по их количеству.
- Живая синхронизация между всеми открытыми вкладками через Server-Sent Events.
- MCP-сервер (Streamable HTTP) с инструментами `get_dashboard`, `list_tasks`, `add_task`, `update_task`, `set_task_done`, `delete_task`, `set_goal`.
- Защита: basic-auth для сайта и API, секретный путь для MCP-эндпоинта.
- Тесты хранилища, REST API и MCP, Dockerfile.

### История дизайна (до репозитория)
Интерфейс прошёл несколько итераций в прототипе: девять вариантов оформления (дашборд, кольца, квест-лог, роадмап, гонка, вкладки, доска, список, фокус) → команда выбрала дашборд и кольца → единый иерархичный дашборд по статье Ozon Tech «Дашборды: между красотой и эффективностью» → цветные бары скоупов и доли на общем баре → убраны счётчики задач, привязка к датам и легенда.
